# Landing Site UI Kit

Recreation of the MedPrüf marketing landing page (Wien Kenntnisprüfung).

**Files**
- `Hero.jsx` — top nav, hero section with product mockup, stat strip
- `Sections.jsx` — Features grid, Subjects grid, Pricing (Free / Pro / Group), Footer
- `index.html` — composed landing page

Primitive components (Icon, LogoMark, Buttons, Card) are imported from `../web_app/Primitives.jsx` — one source of truth across kits.

Open `index.html` to view.
