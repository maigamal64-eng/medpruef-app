# Web App UI Kit

Hi-fi recreation of the MedPrüf web application — sidebar + home, quiz flow, progress.

**Files**
- `Primitives.jsx` — Icon, LogoMark, Wordmark, Button family, Badge, Card
- `Sidebar.jsx` — dark Oxford-Blue nav column with collapse toggle
- `HomeScreen.jsx` — hero banner, daily-goal ring, streak, XP, topic grid
- `QuizScreen.jsx` — question card with answered state + explanation drawer
- `ProgressScreen.jsx` — stat tiles, activity heatmap, strengths, line chart
- `index.html` — interactive click-through demo (navigate via the sidebar)

Open `index.html` to run it.
